# 安全与数据说明

## 数据分类

| 类型 | 仓库是否允许 | 说明 |
|---|---|---|
| 合成 RFQ、报价和供应商样例 | 允许 | 必须标注 synthetic / mvp_seed |
| `.env.example` 占位配置 | 允许 | 不得包含可用密钥 |
| 真实 API Key / Token | 禁止 | 只通过本地环境变量或密钥系统注入 |
| 真实供应商与客户数据 | 禁止 | 需脱敏后才可进入私有评测环境 |
| 数据库、缓存、日志、Trace | 禁止 | 由 `.gitignore` 排除 |
| 会话记忆与用户偏好 | 禁止 | 运行时保存在本地/私有基础设施 |

## AI 安全边界

- 模型输出不可替代确定性业务校验；
- Hard Constraint 结果不可被解释层覆盖；
- 不存在的供应商、价格、认证和交期不得生成；
- 供应商字段缺失时输出 `unknown`；
- 询价、谈判、定标、合同、付款与下单必须人工确认。

## 工程保护

- Tool 顺序断言；
- 循环调用检测；
- 工具超时、重试和熔断；
- 输出内容过滤；
- 请求级 Token 预算；
- 会话级事件、错误和降级状态记录。

## 发布前检查

1. 确认无 `.env`、数据库、缓存、日志和构建产物；
2. 运行密钥模式扫描；
3. 确认评测数据均为合成数据；
4. 运行测试和离线评测；
5. 检查 README 不包含客户、ROI 或生产能力的夸大声明。
